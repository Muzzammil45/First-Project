# BallersHQ — Welcome Page

A welcome page for new members of **BallersHQ**, a sports-arena booking platform, built with plain HTML and CSS. It greets the user, summarises what they can do on the platform, and leads them to sign in.

**Live:** https://muzzammil45.github.io/First-Project/

## Features

- Branded header with logo and personalised greeting
- Feature summary: find arenas, manage court bookings, connect with friends and teams
- Sign-in call to action
- Footer with contact details and social links (Font Awesome icons)
- Custom typography with Google Fonts (Rethink Sans)

## Tech

HTML5 · CSS3 · Google Fonts · Font Awesome

## Run it

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

```
index.html   page markup
style.css    layout and styling
images/      logo and header photo
```
